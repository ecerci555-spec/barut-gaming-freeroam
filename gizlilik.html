BARUT GAMING / BİLGİLENDİRME

GİZLİLİK BİLGİLERİ.

Son güncelleme: 20 Kasım 2026. Bu sayfa, Barut Gaming'in herkese açık tanıtım web sitesinin mevcut işleyişini açıklar; yasal bir gizlilik garantisi veya sunucuda özel hesap altyapısı bulunduğu anlamına gelmez.

Önemli: Şikâyet, script önerisi ve video başvuruların GitHub Issues üzerinde herkese açık olabilir. Kişisel bilgiler, telefon numaraları, adresler, parolalar, IP adresleri veya özel yazışmalar yükleme.

1. Sitenin altyapısı

Barut Gaming web sitesi GitHub Pages üzerinde yayımlanan statik bir sitedir. Kendi kullanıcı şifresi veritabanı, özel oturum doğrulama hizmeti veya doğrudan siteye video depolama hizmeti bulunmaz.

2. Kayıt Ol / Giriş Yap düğmeleri

Bu düğmeler GitHub hesabı açma veya GitHub üzerinden giriş seçeneklerini gösterir. GitHub hesabı MTA:SA oyun hesabı değildir. Sitede “GitHub İşlemini Tamamladım” seçeneği kullanılırsa Kayıt Ol / Giriş Yap düğmelerini gizleyen yalnızca görsel bir tercih bu tarayıcıda tutulur. Bu tercih kullanıcı kimliğini doğrulamaz. Siteye şifre girme.

3. Tarayıcıda saklanan tercihler

Site dil seçimi ve hesap düğmelerini gösterme/gizleme tercihi gibi küçük ayarları tarayıcının yerel depolama alanında tutabilir. Bu veriler site tasarımını kişiselleştirmek içindir; bir kullanıcı hesabı oluşturmaz.

4. Oyuncu şikâyetleri, script önerileri ve video gönderimleri

Bu başvurular GitHub Issue formları üzerinden iletilir. GitHub hesabın, yazdığın metinler, fotoğraf/video ekleri ve verilen bağlantılar GitHub üzerinde herkese açık olabilir. Videonun haftalık vitrinde yayınlanması için yönetici onayı gerekir, ancak onaysız GitHub başvurusu da herkese açık olabilir. Yüklediğin videonun kamuya açık paylaşımını kabul ettiğinden emin ol.

5. Sunucu oyuncu listesi

Web sitesi MTA:SA sunucusunun herkese açık sorgu verilerinden oyuncu sayısını ve erişilebildiğinde oyun içi takma adları gösterebilir. Bilgiler gecikmeli olabilir. Web sitesinin bu alanda oyuncuların IP adreslerini veya seri numaralarını yayımlama amacı yoktur.

6. Dış hizmetler ve ziyaretçi sayacı

Sitede GitHub, harici görüntü sağlayıcıları, YouTube video oynatıcıları ve whos.amung.us/waust.at ziyaretçi sayacı bulunabilir. Bu hizmetler kendi gizlilik politikaları uyarınca IP adresi, tarayıcı bilgisi veya çerez gibi veriler işleyebilir. Web sitesine bu hizmetler için özel bir gizlilik garantisi verilmez.

7. Bağlantılar, yönetim ve talepler

Şikâyet/öneri kayıtlarına yapılan yorum ve değişiklikler GitHub üzerinden yönetilir. Kendi başvurularını ve eklerini yönetme veya kaldırma konusunda GitHub hesabındaki seçenekleri kullanabilirsin. Bir gönderinin silinmesi, içeriğin başka kişilerce daha önce kaydedilmiş kopyalarının da silindiğini garanti etmez.

GitHub'un kendi gizlilik politikası için GitHub Gizlilik Bildirimi sayfasını inceleyebilirsin.
