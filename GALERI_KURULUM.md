# Barut Gaming Galeri Upload (10 screenshot)
1. This repository's public gallery section is ready to display uploaded real in-game photos.
2. Go to https://github.com/ecerci555-spec/barut-gaming-freeroam/upload/main
3. Upload a single file named **barut-gallery.zip**, then press **Commit changes**.
4. The `Galeri Fotograflarini Yukle` GitHub Action checks the ZIP and commits the images into `assets/gallery/`.
5. The gallery becomes visible automatically because the website loads the actual images directly from raw.githubusercontent.com when present.

Images: 3 panels (F1/F2/F3), 4 CJ outfits (black and white front/back), and 3 motorcycle screenshots.

Note: A screenshot of an in-game car has not been supplied yet. The current site already has a separate sports-car promotional image.
